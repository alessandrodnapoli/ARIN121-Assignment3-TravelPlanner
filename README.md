# ARIN121-Assignment3-TravelPlanner

This planner helps travellers build an itinerary, compare transportation
options, adjust an existing plan, or choose between destinations.

To use it, paste the contents of system-prompt.md into System instructions
in Google AI Studio. Start with “Can you help me with a trip?” to see the
menu. You can choose a number, name an activity, or ask in your own words.

For example, ask “Can you help me choose between Dijon and Paris?” The
planner asks what matters most to you and uses your answer to compare the
two places. You can switch activities at any point. If you say “I’ve picked
Dijon. How should I get there?”, it carries over relevant details you
already gave, such as where you’re leaving from and how long you have.
